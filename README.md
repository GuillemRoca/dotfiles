# dotfiles

Personal dotfiles for dev environment setup.

## What's included

- **Claude Code** (`claude/`) - settings and status line script

## Setup

```bash
git clone git@github.com:GuillemRoca/dotfiles.git ~/dotfiles
cd ~/dotfiles
./install.sh
```

### Prerequisites

- [jq](https://jqlang.github.io/jq/) - required by the status line script (`brew install jq`)
